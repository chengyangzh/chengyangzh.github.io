**Echo** is a compact agent runtime built around a repeated decide–act–observe loop. It combines structured analogy retrieval, persistent SQLite sessions, tool use, explicit selected/rejected mappings, and deterministic evaluation cases that separate structural relevance from surface similarity.

The project includes a CLI workflow and controlled cases for near analogies, far analogies, surface traps, and unrelated examples.
