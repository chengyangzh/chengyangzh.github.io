01 · agent systems

Echo

Minimal agent runtime · structure-first analogy retrieval

Built a compact agent runtime around a repeated decide–act–observe loop, with persistent sessions, tool use, structured analogy retrieval, and controlled evaluation. The system separates structural matching from surface similarity and records selected/rejected analogies, mappings, and failure boundaries.

Implemented a CLI workflow, SQLite transcript persistence, compact observation handling, and deterministic tests for near analogies, far analogies, surface traps, and unrelated cases.

02 · historical NLP

Philologist-inspired phonological reconstruction

University of Cambridge · Prof. Weiwei Sun

Developed category-based optimization models for joint Middle Chinese–Old Mandarin reconstruction, using distinctive features, modern dialect reflexes, fanqie, rhyme-table structure, and explicit cross-period historical constraints.

Extended the historical representation with additional time planes reconstructed from Wang Li’s phonological system and evaluated model outputs against philological reconstructions and Sino-Xenic evidence.

04 · clinical ML

Tengyun dialysis prediction system

Peking University Century Jinyuan Clinical Translation Project

Developing a hybrid physics-informed machine learning system for hemodialysis adequacy prediction and prescription optimization. Trained XGBoost and CatBoost models for spKt/V and HDF convective volume on 246,590 longitudinal sessions with patient-level and temporal validation.

Built an interactive decision-support tool for recommending blood-flow-rate and treatment-duration combinations.

05 · semantic change

Diachronic Chinese semantic change

UCLA Undergraduate Research Week · Prof. Sam Cumming

Constructed a 23M-character diachronic corpus, trained period-specific Word2Vec models, aligned embedding spaces with Orthogonal Procrustes, and engineered contrastive semantic axes to track pejorative, urban-coding, and cultural-identity trajectories.
